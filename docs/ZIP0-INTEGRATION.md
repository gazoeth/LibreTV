# ZIP0 参考体验整合记录

更新日期：2026-10-18。目标项目：FreeDY（LibreTV-main 2）。

## 已观察的参考站行为

- `https://zip0.com/tv`：地区目录在客户端加载，按国家／地区展示旗帜、名称与频道数量；常用地区优先，点击进入 `/watch-tv?country=地区名`。
- 参考站页面本次显示 178 个地区、8,928 个频道。这是参考站自己的目录数量，不作为 FreeDY 数据或播放验证结果。
- 公开发布的 `tv-ByTyVDQl.js` 与 `RegionDirectory-Cr9UDazw.js` 印证了地区分组、常用地区排序和观看页跳转；这属于公开脚本观察，不是原始源码或完整后台逆向。
- `https://zip0.com/`：搜索优先，常用内容入口、来源比较、精选内容与使用说明构成连续层级。
- 本次没有可调用的 REA MCP 工具；使用普通 HTTP 和独立 Playwright 浏览器检查公开页面及发布脚本，没有产生 REA Evidence ID。

## FreeDY 已整合

1. 新增 `/tv` 全球电视大厅，展示真实地区／频道数、常用地区筛选、地区搜索、空结果与加载失败状态。
2. 地区卡片进入 `/live?country=CN` 等观看页；地区内频道复用现有搜索、分组、虚拟列表、测活、收藏、最近观看和上一台／下一台能力。
3. 换台后地区参数保留，刷新或分享链接仍处于同一地区；观看页可直接切换地区，切换时清除旧地区的频道筛选。直接打开原 `/live` 仍显示用户已启用的直播订阅。
4. 窄屏首次进入时直接显示频道列表；900px 起使用桌面双栏布局。选择频道后移动端频道抽屉仍可呼出。
5. 导航统一增加“看电视”，电视大厅、观看页与首页使用同一品牌、色彩、层级与焦点规则。
6. 首页增加内容探索入口与可展开的点播来源列表，读取真实源数量及用户选择状态；示例搜索明确展示实际片名。
7. 采用 FreeDY 自己的地球图形、版面、空白和渐进交互，支持减少动效偏好。

## 数据与更新

公开频道数据来自 https://github.com/iptv-org/iptv 及 https://iptv-org.github.io/api/ 的 channels、streams 目录。

`src/data/tv-directory.json` 为构建时随项目发布的快照；目录 API 只返回地区汇总或当前地区频道，浏览器不下载完整频道快照。频道按唯一 ID 去重，中文地区优先使用已有中文别名，并标明具体语言信号；官方网站域名内的流地址优先，仅收录 HTTP(S) HLS／FLV 地址；排除明确成人、关闭、需额外 User-Agent／Referer 的条目。

更新命令（Node.js）：`node tools/update-tv-directory.mjs`。更新失败或条目数量异常时保留旧快照。支持 `--input-dir` 读取指定文件夹内的 channels.json、streams.json 以便复现。

频道数量表示目录收录，不表示当前网络逐一验证可播放；可在观看页测活。地区限制、上游停播和流地址变化仍会导致个别频道不可用。

## 影视、广播与播放体验补充

- 参考公开 `/category/movie` 等页面的分类、来源反馈、点击播放与选集交互，新增 `/films?type=movie`；支持电影、短剧、电视剧、综艺、纪录片、动漫、体育七类。服务端读取来源真实叶级分类，支持换源和分页；自动模式有限回退，不伪称全源聚合或提供未实现的地区／年份筛选。
- 封面直接播放，独立按钮打开选集与详情。悬停停留或键盘聚焦预热详情，最多两个并发；详情面板、线路检测与播放页共用五分钟详情缓存。
- 线路搜索以 NDJSON 逐源返回，详情最多四路并发；候选到达即可显示，详情成功即可手选，不等待所有慢源。单独显示详情耗时和媒体清单／分片可达状态，避免将接口响应速度解释为视频速度。关闭面板取消剩余工作，服务端也传递取消信号，取消结果不污染搜索缓存。
- 播放启动超时提供检测其他线路入口，快速换集清理旧媒体监听和恢复任务。沿用既有 HLS 广告过滤和代理回退。
- `/radio` 提供 126 个地区、1,749 个电台的 Radio Browser HTTPS 快照，含地区搜索、台名搜索、收藏、最近收听、固定音频播放器、重试、音量和系统媒体控制。收藏与历史存于本机；不等于账号同步。
- 广播快照更新：`node tools/update-radio-directory.mjs`。上游 lastcheckok 与目录收录不等于所有用户网络实时可播。

### 补充核验边界

- 七类目录均获得真实上游影片；非法分类、来源、页码被拒绝。
- 受控慢源浏览器场景：慢源设为 4,500ms，首条替代线路约 306ms 可选；详情面板到播放页、切线路到播放页均只请求一次详情，关闭后剩余搜索被取消。这是受控回归结果，不是 ZIP0 与 FreeDY 公网速度对比。
- Radio Paradise World/Etc、怀集音乐之声、Heart 80s 的 HTTP 样本取得 200 和音频字节；SomaFM 样本在当前网络连接失败，界面提供重试。随后 Radio Paradise World/Etc 320k AAC 在 Chrome 浏览器取得 readyState=3、播放时间前进，约 1.3 秒开始播放；这是单台短时样本，不等于全部电台持续稳定。
- 生产构建通过，搜索取消、播放恢复与兼容相关 20 项测试通过；额外受控媒体事件核验确认旧电台事件不会干扰新台，暂停意图不会被迟到事件覆盖，320px 无横向溢出。
- 核验记录和桌面／移动截图：`artifacts/films-radio/`。按字体、留白、信息层级、焦点、减少动效、窄屏菜单与横向溢出检查并压缩片库首屏，优先让内容进入视野。奖项为设计目标，不代表已获奖或客观保证不存在任何改进空间。

## 2026-10-18 整站体验第二轮（以此节为当前行为）

本节更新前文的单源默认、导航及线路弹窗描述；此前的核验数字保留为历史记录，不代表本次重新执行了测试套件。

- 全站共享炭黑／荧光绿主题，统一 PC 导航和移动抽屉；导航提供搜索、本机影视收藏、历史和来源设置。复用抽屉焦点处理，并统一滚动锁所有权，避免抽屉交接后背景无法滚动。
- 首页增加真实近期电影／电视剧／短剧／综艺／动漫目录和本机续播。目录在接近视口时加载，点击封面直接播放。
- 搜索页面采用海报栅格、封面直达播放、可展开来源选择和搜索接口健康面板。
- 分类页默认请求前 10 个启用的内置来源，3 并发、每源 8 秒预算，NDJSON 逐源展示与同名同年去重；分页指各源自己的第 N 页，不虚构总数。默认先请求父分类，空父分类才回退叶分类并明确显示范围。单源显式选择分类不自动改变。
- 移动端将详细筛选收进可展开面板，PC默认展开。地区、年份、年代与排序只处理当前已加载结果，选项来自真实字段，未知值明确展示；不宣称服务器全量筛选或未提供的评分。
- 播放右栏常驻线路列表，可切为展开面板，复用同一实例而不重启检测。接口／清单／分片状态区分，线路位置稳定；重试当前播放器不会刷新页面。补齐真实影片资料、纯文本简介和分享链接。
- 影视本机收藏最多 200 项、1MB，有去重、坏数据与存储失败处理、跨标签更新；不上传，不提供账号云同步。清理浏览器数据会丢失收藏。
- 电视／广播增加地区快捷入口、紧凑目录与移动触控布局；广播当前电台可暂停恢复，电视在手机播放器下方仍可选台，并保留安全区快捷频道抽屉。
- Pages 产物生成唯一公共文件路径表，旗帜和播放器封面等资源正确走静态资源，不再依赖手工枚举几个路径。

参考页面：ZIP0 首页、电视剧分类、实际点播页、电视目录及电视观看页。仅观察公开 UI、公开 HTML/CSS 与运行行为；未获得第三方后台原始源码、私有账户数据或授权凭据。当前未实现音乐、游戏、云账户、评论、公共收藏与分享收益；不以静态假界面替代真实服务。
